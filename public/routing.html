Tag routing

Preferred agents

When a caller has several tags, the enabled rule with the lowest priority number and an available agent wins. That agent rings first. If they do not answer, the normal team rings, followed by voicemail. Business hours and availability still apply.

Caller routing tags

These tags apply to future calls from this phone number. Multiple tags are supported. Call-history tags and follow-up owners stay separate. Shared transfer-source numbers cannot be tagged.

Up to 20 tags, 40 characters each. Clear the field to remove all routing tags.
